# Miguel Espinosa — Portfolio

Portfolio web profesional creado a partir del CV y la fotografía proporcionados.

## Ejecutar

No requiere build ni dependencias para la versión estática:

```bash
python3 -m http.server 8080
```

Abrir `http://localhost:8080`.

## Publicar

Esta carpeta se puede desplegar directamente en GitHub Pages, Netlify, Cloudflare Pages o cualquier hosting estático.

## Contenido

- `index.html` — estructura y contenido.
- `styles.css` — identidad visual, responsive y accesibilidad.
- `script.js` — microinteracciones y terminal interactiva.
- `public/profile.png` — fotografía proporcionada.
- `public/CV-Miguel-Espinosa.pdf` — CV original, como descarga opcional.

## Nota editorial

Las fechas y textos se han normalizado únicamente para presentación web cuando el PDF contiene erratas evidentes. No se han añadido empresas, tecnologías, certificaciones o logros que no aparezcan en el material proporcionado.
